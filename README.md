# 🎯 Samurai Sword Frontend

Interface web pour le jeu de cartes multijoueur Samurai Sword. Frontend léger développé en PHP, HTML, CSS et JavaScript vanilla.

## 🚀 Technologies

- **PHP 8.3+** - Serveur backend léger
- **HTML5** - Structure des pages
- **CSS3** - Styles et animations
- **JavaScript (Vanilla)** - Interactivité côté client
- **WebSockets** - Communication temps réel avec l'API


## ⚙️ Installation et Démarrage

### Prérequis

- **PHP 8.3+** avec serveur web intégré
- **Navigateur web moderne** (Chrome, Firefox, Safari, Edge)
- **API Samurai Sword** démarrée et accessible

### Démarrage du serveur

```bash
# Se placer dans le dossier frontend
cd SamuraiSwordFo

# Démarrer le serveur PHP intégré
php -S localhost:8000

```

### Accès à l'application

- **URL principale :** http://localhost:8000

## 🔧 Configuration

### Variables d'environnement (optionnel)
Créer un fichier `config.js` pour personnaliser
